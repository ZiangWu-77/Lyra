KeyTone · 离线键音
=================

这是为本机重写的 Swift/AppKit 菜单栏键盘音效工具，非 Mechvibes 官方版本。

保留：14 套本地键盘音色（10 套机械键音 + 3 套趣味合成音 + 1 套真实猫叫）、按下/松开音、音量、静音、试听、菜单栏、Ctrl+Option+M 静音、鼠标点击音效开关、独立鼠标音色/音量/试听、登录时自动启动开关、打字伴奏模式。
不包含：账号、网站、更新检查、统计、社区下载、主题脚本或按键日志。

运行
----
打开 KeyTone.app。可先点“试听键盘”或“试听鼠标”，无需输入监控权限。
全局键音需要在 系统设置 > 隐私与安全性 > 输入监控 中开启 KeyTone。
只使用 listenOnly 事件监听，不请求辅助功能、录屏、麦克风或完全磁盘权限。
若授权后仍不发声，退出并重新打开。macOS 保护的输入区域可能不会发出键音。
鼠标音效默认关闭，可在界面开启；左键、右键、中键分别使用鼠标所选音色的 A、S、空格片段。
鼠标与键盘各自选择 14 套本地音色、音量与试听；静音快捷键和松键音选项仍共同生效。
首次升级会复制原来的音色/音量到鼠标设置，之后分别保存，互不影响。
关闭鼠标监听仍可点击“试听鼠标”；移动、拖动、滚轮及侧键不发声。
取消鼠标音效后，事件监听掩码不再包含鼠标事件。
“登录时自动启动”由系统维护真实状态，可随时关闭；登录启动时不主动弹出主窗口。
长按重复按键和修饰键本身不发声。关闭窗口后继续运行，退出请用菜单栏。

打字伴奏模式（1.4.2）
--------------------
开启后，键盘按下开始或继续播放贝多芬第五交响曲第一乐章的连续开篇录音。
持续打字不切片、不重播、不跳过音乐；任意已监听的普通按键按住期间持续播放。
最后一个按键松开后等待 2 秒才暂停，其间再次按键则继续。
下次按键从暂停时的位置继续。自动重复输入可续播且不累计重复的按住状态；修饰键本身和鼠标点击不触发伴奏。
仅在内存维护当前按住的物理按键，并核对系统按键状态，以恢复可能漏掉的松键事件。
普通机械键音仍过滤长按自动重复，避免连续响。
静音或切回普通键音会立即暂停并保留位置；再次开启模式后等待下次按键续播。
“从头开始”暂停并重置到开头。“试听键盘”播放 2.4 秒后暂停。
当前内置开篇 60 秒，结束后循环；退出应用后播放位置不持久化，下次启动从头开始。
关闭伴奏模式即回到保存的 Cherry 茶轴 ABS；键盘和鼠标原来的设置均保留。
素材保留完整连续音频，仅首尾做 15 毫秒淡入淡出，没有原版的周期性切片处理。
来源及录音授权见 Resources/Orchestra-SOURCE.txt；源录音保存在 SampleSources。
import-orchestra.py 使用本地 afconvert 离线重建素材。运行和构建均不联网。

隐私边界
--------
1. main.swift 最先调用 keytone_lock_network；失败立即退出，不启动键盘监听。
2. OfflineGate.c 使用 macOS Seatbelt 规则拒绝 network*、process-exec、process-fork。
3. 没有 URLSession、WebView、HTTP 客户端、自动更新、下载或遥测代码。
4. 仅允许硬编码的本机系统设置链接，用于用户主动打开输入监控设置。
5. 输入回调仅读取物理键码和按下/松开状态，经内存队列播放音频。
   不读取字符文本、剪贴板、应用窗口标题或用户文件；不保存按键历史。
6. UserDefaults 只保存键盘/鼠标各自的音色 ID、音量，以及静音、松键音、交响乐模式和鼠标音效偏好。
7. 鼠标音效开启后仅读取左/右/中键的按下和松开状态，不读取坐标、移动轨迹或点击内容。
8. 自动启动通过 Apple SMAppService.mainApp 管理，仅启动本应用，不安装额外后台程序。

这不是对所有系统服务的全机断网规则，也不是抵抗被篡改二进制的安全边界。
Seatbelt 的 sandbox_init 是 Apple 已弃用的接口；当前系统实测通过才交付，
未来 macOS 如不再支持，应用会拒绝启动，不会退回无沙盒运行。
本地构建使用 ad-hoc 签名，不是 Developer ID 签名，也没有 Apple 公证。

离线构建与检查
--------------
要求本机已安装 Xcode Command Line Tools。无需 Homebrew、npm、Cargo 或联网。
在本目录运行：bash build.sh
构建结果默认保存到上级目录的 KeyTone.app。

build.sh 自动检查：
- 代码签名结构有效；
- IPv4/IPv6 的 TCP 连接、UDP 发送、socket 绑定均被 OS 权限拒绝，
  ECONNREFUSED 不算通过；测试只使用 loopback 和固定测试字符串；
- 鼠标按下/松开映射、关闭鼠标监听、忽略移动/滚轮/侧键的路由检查；
- 全部 14 套音色和 连续交响乐录音可读取且边界合法；
- 使用真实播放器以零音量验证无重复事件的长按、多键同时按住、重复按下去重、松开后两秒暂停、漏松键恢复、原位置续播、静音与重置。

源码说明
--------
Sources/main.swift：原生界面、设置、本地声音片段、播放及只读键盘监听。
Sources/TypingMusicPlayer.swift：连续音乐播放、按住续播、松开后两秒暂停和原位置续播。
Sources/InputRouting.swift：键盘/鼠标事件掩码与鼠标声音映射。
Sources/OfflineGate.c：进程级禁网规则和隔离验证。
Resources/Sounds：已转换好的 PCM WAV 与片段索引，运行/构建无需原仓库。
import-sounds.py：可选的机械键音重建工具，依赖原始源码目录和系统 afconvert。
make-fun-sounds.py：仅用 Python 标准库离线生成泡泡、橡皮鸭、街机三套原创音效。
import-cat.py：从 SampleSources 内的 CC0 录音离线重建真实猫叫包；保持原音高和时长，降低峰值并添加短淡入淡出，松键静音。
猫叫来源：qubodup / Jofae（Freesound），见 Resources/Cat-SOURCE.txt。
